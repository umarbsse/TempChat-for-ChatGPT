A minimal Chrome extension that redirects the exact root URL:

```text
https://chatgpt.com/
```

to:

```text
https://chatgpt.com/?temporary-chat=true
```

The redirect is implemented with Manifest V3 `declarativeNetRequest`. There is no background script.

## Behavior

- Redirects only `https://chatgpt.com/`
- Does not redirect URLs that already have query parameters
- Does not redirect `https://chatgpt.com/?temporary-chat=true` again
- Includes a toolbar popup toggle to enable or disable the redirect

## Files

- `manifest.json` - Chrome extension manifest
- `rules.json` - Declarative redirect rule
- `popup.html` - Toolbar popup UI
- `popup.js` - Enables or disables the ruleset from the popup

Chrome may create an `_metadata` folder after loading the extension. That folder is generated by Chrome and is not part of the editable source.

## Load Unpacked In Chrome

1. Open `chrome://extensions/`
2. Enable Developer mode
3. Click Load unpacked
4. Select this extension folder

## Use The Toggle

1. Pin the extension from Chrome's extensions menu
2. Click the extension icon in the toolbar
3. Turn Enable redirect on or off

If the extension is already loaded and you edit these files, go back to `chrome://extensions/` and click Reload on the extension card.
